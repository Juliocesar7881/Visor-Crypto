# Visor Crypto - ko-KR

## Short title
Visor Crypto

## Short description
암호화폐 신호, 가격, 뉴스 및 매크로 데이터를 실시간으로 제공합니다.

## Full description
Visor Crypto는 Bitcoin와 알트코인 가격, 기술 신호, 통화 내역, 필터링된 암호화폐 뉴스 및 거시 지표를 하나의 빠른 시장 대시보드에 통합합니다.

기회를 모니터링하고, Fed Watch를 확인하고, 미국 경제 달력을 따르고, 1시간, 2시간, 4시간 결과로 신호 기록을 검토하세요.

신호는 정보 제공용이며 시장 데이터를 기반으로 합니다. 이는 재정적 조언이 아닙니다.
