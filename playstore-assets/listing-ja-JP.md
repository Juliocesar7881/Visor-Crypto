# Visor Crypto - ja-JP

## Short title
Visor Crypto

## Short description
リアルタイムの暗号シグナル、価格、ニュース、マクロデータ。

## Full description
Visor Crypto は、Bitcoin とアルトコインの価格、テクニカル シグナル、通話履歴、フィルタリングされた仮想通貨ニュース、マクロ指標を 1 つの高速市場ダッシュボードにまとめます。

機会を監視し、Fed Watch をチェックし、米国の経済カレンダーに従い、1 時間、2 時間、4 時間の結果でシグナル履歴を確認します。

シグナルは情報を提供するものであり、市場データに基づいています。これらは経済的なアドバイスではありません。
