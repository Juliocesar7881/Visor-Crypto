# Visor Crypto - is-IS

## Short title
Visor Crypto

## Short description
Dulritunarmerki, verð, fréttir og þjóðhagsgögn í rauntíma.

## Full description
Visor Crypto færir Bitcoin og altcoin verð, tæknimerki, símtalasögu, síaðar dulmálsfréttir og þjóðhagsvísa í eitt hratt markaðsmælaborð.

Fylgstu með tækifærum, athugaðu Fed Watch, fylgdu bandaríska efnahagsdagatalinu og skoðaðu merkjasögu með 1 klst, 2 klst og 4 klst útkomu.

Merki eru til upplýsinga og byggjast á markaðsgögnum. Þeir eru ekki fjármálaráðgjöf.
