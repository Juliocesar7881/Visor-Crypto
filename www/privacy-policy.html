Política de Privacidade

Última atualização: 26 de fevereiro de 2026

O aplicativo Visor Crypto ("nós", "nosso" ou "aplicativo") respeita sua privacidade. Esta política descreve quais dados coletamos, como os usamos e seus direitos.

1. Dados que Coletamos

1.1 Dados que NÃO coletamos

  • Não coletamos nome, email, telefone ou qualquer dado pessoal identificável
  • Não exigimos cadastro ou login
  • Não coletamos dados de localização (GPS)
  • Não acessamos câmera, microfone, contatos ou arquivos do dispositivo

1.2 Dados armazenados localmente

O aplicativo armazena dados apenas no seu dispositivo (localStorage), incluindo:

  • Histórico de análises técnicas realizadas
  • Configurações de preferência (notificações, criptomoedas favoritas)
  • Cache de dados de mercado para performance

Estes dados nunca saem do seu dispositivo e são apagados se você desinstalar o app ou limpar os dados.

1.3 Dados de uso anônimos

Podemos coletar dados de uso anonimizados para melhorar o aplicativo:

  • Tipo de dispositivo e versão do Android (via Google Play)
  • Relatórios de crash anônimos (se disponível)
  • Estatísticas agregadas de uso (sem identificação pessoal)

2. Publicidade (AdMob)

O aplicativo exibe anúncios via Google AdMob. O Google pode coletar:

  • Identificador de publicidade do dispositivo (GAID)
  • Dados de interação com anúncios
  • Informações técnicas do dispositivo

Para mais informações sobre como o Google usa dados de publicidade, consulte: Política de Privacidade do Google.

Você pode optar por não receber anúncios personalizados nas configurações do seu dispositivo Android (Configurações → Google → Anúncios).

3. APIs e Serviços Externos

O aplicativo consulta APIs públicas para obter dados de mercado:

  • Binance API — Preços, volumes, order books de criptomoedas
  • CoinGecko API — Market cap, dominância, índices
  • Yahoo Finance — Dados de mercados tradicionais (S&P 500, DXY, etc.)
  • Mempool.space — Dados on-chain de Bitcoin

Estas consultas são feitas diretamente do seu dispositivo. Nenhum dado pessoal é enviado a estes serviços.

4. Backend do Aplicativo

Algumas funcionalidades utilizam nosso servidor backend para:

  • Proxy de APIs externas (proteção de chaves de API)
  • Análise de regime macroeconômico
  • Estatísticas agregadas e anônimas de setups

O backend não armazena dados pessoais. Requisições são processadas sem identificação do usuário.

5. Segurança

Adotamos as seguintes medidas de segurança:

  • Todas as comunicações usam HTTPS (criptografia em trânsito)
  • Dados sensíveis ficam apenas no dispositivo local
  • Nenhuma senha ou credencial de exchange é armazenada
  • O código nativo é ofuscado via ProGuard

6. Crianças

O aplicativo não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de crianças. Se você é menor de 18 anos, não utilize este aplicativo.

7. Seus Direitos

Você pode a qualquer momento:

  • Apagar dados locais: Configurações do Android → Apps → Visor Crypto → Limpar dados
  • Desativar anúncios personalizados: Configurações → Google → Anúncios
  • Desinstalar o aplicativo: Todos os dados locais serão removidos

8. Aviso Legal Financeiro

Este aplicativo é meramente informativo e educacional. NÃO constitui recomendação de investimento, consultoria financeira ou solicitação de compra/venda de qualquer ativo.

Investimentos em criptomoedas envolvem alto risco de perda total do capital investido. Faça sua própria pesquisa (DYOR) antes de tomar qualquer decisão financeira.

9. Alterações nesta Política

Podemos atualizar esta política periodicamente. A data de "Última atualização" no topo indica quando foi revisada pela última vez. Recomendamos revisar esta página ocasionalmente.
