Política de Privacidade

Última atualização: 16 de setembro de 2026

O aplicativo Visor Crypto ("nós", "nosso" ou "aplicativo") respeita sua privacidade. Esta política descreve quais dados coletamos, como os usamos e seus direitos.

1. Dados que Coletamos

1.1 Dados que NÃO coletamos

  • Não coletamos nome, email, telefone ou qualquer dado pessoal identificável
  • Não exigimos cadastro ou login
  • Não coletamos dados de localização (GPS)
  • Não acessamos câmera, microfone, contatos ou arquivos do dispositivo

1.2 Dados armazenados localmente

O aplicativo armazena localmente no seu dispositivo (localStorage e preferências do Android):

  • Histórico de análises técnicas realizadas
  • Configurações de preferência (notificações, criptomoedas favoritas)
  • Cache de dados de mercado para performance

O cache e as preferências locais são apagados se você desinstalar o app ou limpar seus dados. Somente os identificadores técnicos e eventos descritos nas seções 1.4 e 4 podem ser enviados ao backend.

1.3 Dados de uso anônimos

Podemos coletar dados de uso anonimizados para melhorar o aplicativo:

  • Tipo de dispositivo e versão do Android (via Google Play)
  • Relatórios de crash anônimos (se disponível)
  • Estatísticas agregadas de uso (sem identificação pessoal)

1.4 Notificações e alertas

Quando você ativa notificações, o Firebase Cloud Messaging (FCM) processa um token técnico e inscrições em tópicos por criptomoeda. Durante a compatibilidade com versões antigas, o aplicativo também pode registrar no backend um identificador pseudônimo, o token FCM, preferências de alerta e dados mínimos para entregar sinais e evitar duplicidade.

Esses dados são usados somente para operar notificações e sincronização de sinais. Você pode desativar os alertas no app ou nas configurações do Android; ao desativar, o app tenta remover o token remoto associado.

Registros pseudônimos de dispositivo, token FCM e preferências de notificação são mantidos apenas pelo tempo necessário para operar o serviço, em geral por até 90 dias após a última sincronização ou até a remoção/expiração operacional do token.

2. Publicidade (Appodeal)

O aplicativo pode exibir anúncios limitados via Appodeal. Conforme a região e suas escolhas de privacidade, a Appodeal e as redes habilitadas podem processar:

  • Identificador de publicidade do dispositivo (GAID)
  • Dados de interação com anúncios
  • Informações técnicas do dispositivo

Para mais informações, consulte a Política de Privacidade da Appodeal. Quando exigido, o aplicativo apresenta o fluxo regional de consentimento antes de solicitar anúncios personalizados e oferece uma opção para revisar escolhas de privacidade.

3. APIs e Serviços Externos

O aplicativo consulta APIs públicas para obter dados de mercado:

  • Binance API — Preços, volumes, order books de criptomoedas
  • CoinGecko API — Market cap, dominância, índices
  • Yahoo Finance — Dados de mercados tradicionais (S&P 500, DXY, etc.)
  • Mempool.space — Dados on-chain de Bitcoin

As consultas globais e de maior custo são feitas preferencialmente pelo nosso backend com cache compartilhado. Algumas consultas de mercado podem usar conexão direta como contingência. Não enviamos nome, email, telefone ou credenciais de exchange a esses provedores.

4. Backend do Aplicativo

Algumas funcionalidades utilizam nosso servidor backend para:

  • Proxy de APIs externas (proteção de chaves de API)
  • Análise de regime macroeconômico
  • Estatísticas agregadas e anônimas de setups
  • Registro técnico de tokens de notificação quando os alertas são ativados

O backend não exige nome, email, telefone, documentos ou credenciais de exchange. Alguns recursos usam identificadores técnicos pseudônimos, como device ID e token FCM, apenas para autenticação curta, sincronização, entrega de notificações e prevenção de abuso.

5. Segurança

Adotamos as seguintes medidas de segurança:

  • Todas as comunicações usam HTTPS (criptografia em trânsito)
  • Dados sensíveis e credenciais de exchange não são solicitados pelo aplicativo
  • Nenhuma senha ou credencial de exchange é armazenada
  • O código nativo é ofuscado via ProGuard

6. Crianças

O aplicativo não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de crianças. Se você é menor de 18 anos, não utilize este aplicativo.

7. Seus Direitos

Você pode a qualquer momento:

  • Apagar dados locais: Configurações do Android → Apps → Visor Crypto → Limpar dados
  • Revisar escolhas de publicidade: use "Opções de privacidade de anúncios" no aplicativo quando essa opção estiver disponível para sua região
  • Solicitar exclusão de dados pseudônimos: envie um email para o contato abaixo informando que deseja remover registros de notificação associados ao seu dispositivo
  • Desinstalar o aplicativo: Todos os dados locais serão removidos

8. Aviso Legal Financeiro

Este aplicativo é meramente informativo e educacional. NÃO constitui recomendação de investimento, consultoria financeira ou solicitação de compra/venda de qualquer ativo.

Investimentos em criptomoedas envolvem alto risco de perda total do capital investido. Faça sua própria pesquisa (DYOR) antes de tomar qualquer decisão financeira.

9. Alterações nesta Política

Podemos atualizar esta política periodicamente. A data de "Última atualização" no topo indica quando foi revisada pela última vez. Recomendamos revisar esta página ocasionalmente.
